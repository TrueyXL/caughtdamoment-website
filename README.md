# CaughtDaMoment — Wedding Videography

Website for CaughtDaMoment, bilingual (English / French) wedding videographers serving Ottawa, Montreal & Quebec.

Live site: https://trueyxl.github.io/caughtdamoment-website/

## What's here
- `index.html` — the whole site (styles, scripts, and images are inside this one file)
- `hero-4k.mp4`, `hero-1080.mp4`, `hero-poster.jpg` — opening video (4K for large screens, 1080p for phones)
- `preview-1/2/3.mp4` — portfolio hover previews
- `clouds.webp`, `clouds-day.webp` — drifting cloud backgrounds (dark / light mode)
- `fonts/` — Marcellus heading fonts

No build step: edit `index.html` and push — GitHub Pages republishes automatically.
